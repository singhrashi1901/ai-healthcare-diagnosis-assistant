## 🌟 Overview

**AI Healthcare Diagnosis Assistant** is a web-based Machine Learning project designed
to provide a preliminary analysis of symptoms and medical reports.

The application allows users to:

- 🩺 Enter symptoms in natural language
- 🤖 Predict a possible disease using a KNN-based ML model
- 📄 Upload medical reports in PDF format
- 🖼️ Upload medical report images
- 🔍 Extract text using OCR
- 🧠 Detect recognizable symptoms from extracted text
- 📊 Generate a preliminary prediction

> ⚠️ **Disclaimer:** This project is developed for educational and demonstration
> purposes only. It is not a replacement for professional medical diagnosis,
> medical advice, or treatment.
